# Frontend Engineer Career Portfolio

에듀토셀에서 진행한 프론트엔드 프로젝트와 성과를 정리한 경력 포트폴리오입니다.

## Live site

https://frontend-career-portfolio-2026.thfpdhk1.chatgpt.site

## Highlights

- 사내 교재관리 ERP 구축
- TOSEL 명예의 전당 및 공식 홈페이지 리뉴얼
- `@edu-tosel/design` 디자인 시스템 구축·배포
- TOSEL VOCA Check 및 운영팀 Admin 개발
- 인사혁신처 성적 연동과 AI 문제 생성 시스템 협업

## Stack

- React
- Next.js-compatible vinext runtime
- TypeScript
- Tailwind CSS

## Local development

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

배포용 빌드 확인:

```bash
npm run build
```
